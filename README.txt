ONLINE COURSE REGISTRATION SYSTEM - ATTRACTIVE EDITION
========================================================
1. Extract this folder into C:\xampp\htdocs\online_course
2. Start Apache and MySQL in XAMPP.
3. Open http://localhost/phpmyadmin
4. Import sql/course_db.sql
5. Open http://localhost/online_course/

Workflow:
Student Registration -> Login -> Dashboard -> Courses -> Course Details
-> Register Course -> Payment Simulation -> Payment Success -> Bill/Receipt
-> Print Bill -> My Courses

The six JPG course images are included and use a dark blue/neon technology style inspired by the uploaded reference image.
Payment is a demo/simulation for an academic project; it does not process real money.
