# Online Course Registration System

A web-based Online Course Registration System developed using PHP, MySQL, Bootstrap, HTML and CSS.

## 📌 Project Description

The Online Course Registration System allows students to register, login, browse available courses, view course details, register for courses, make payments and generate bills.

The system also provides an admin dashboard for managing courses, students and payments.

## 🛠️ Technologies Used

- MySQL
- HTML
- CSS
- Bootstrap
- XAMPP
- Git
- GitHub

## 🗄️ Database

The database file is available in:

`sql/course_db.sql`

## ▶️ How to Run

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the project folder into `C:\xampp\htdocs\`
4. Open phpMyAdmin.
5. Create the database.
6. Import `sql/course_db.sql`.
7. Open the project in your browser.
